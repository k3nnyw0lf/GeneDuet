# GeneDuet — Offspring Trait Inheritance Predictor

**Date:** 2026-06-14
**Status:** Design — pending user approval
**Author:** Kenneth Wolf + Claude

> Working name `geneduet` (alternatives: `kindred`, `punnett`, `heredita`). Easy to rename before the repo goes public.

---

## 1. Purpose

A privacy-first web app where a couple uploads their consumer-DNA raw files (AncestryDNA / 23andMe / MyHeritage / FamilyTreeDNA) and sees the **probability distribution of traits in a hypothetical child** — computed entirely in the browser. Three result domains:

1. **Traits (the centerpiece)** — two-parent Mendelian / probabilistic inheritance for ~40 sourced traits.
2. **Health / carrier screening** — recessive-condition risk to offspring, framed as educational.
3. **For-fun looks** — clearly-labeled novelty appearance odds.

The differentiator vs every existing open-source tool (`arv`, `dna-traits`, `OSGenome`, `GeneMatch-AI`): those describe **one person's** trait via a single-SNP lookup. **GeneDuet combines both parents into a real offspring probability distribution**, with multi-SNP models, X-linked handling, vendor-strand correctness, honest confidence tiers, and an extensible catalog.

### Non-goals (YAGNI / honesty)
- No baby **face/photo** generation (junk science + privacy hazard).
- No polygenic scores for **height, IQ, personality, complex disease** — not reliably predictable for one future child.
- No accounts, no backend, no analytics, no network calls of any kind.

---

## 2. Scientific honesty & licensing

- Consumer raw data is **not clinical-grade** (genotyping errors, false positives, partial variant coverage). Every health/carrier output says *educational — confirm with a doctor / genetic counselor*.
- Each trait carries a **confidence tier**: `high` (well-established single locus), `medium` (main locus, but polygenic), `fun` (weak evidence / novelty).
- **Myths we deliberately exclude** (and say so, for credibility): tongue rolling, widow's peak, hitchhiker's thumb, hand-clasping, finger-length personality — none are reliably single-gene.
- **Licensing:** `arv` and `dna-traits` are **GPLv3** — we do **not** copy their code. GeneDuet is **MIT**, built clean-room from public SNP facts (rsIDs + allele→phenotype come from SNPedia / dbSNP / cited PMIDs, which are data, not their source). Every catalog entry cites a source.

---

## 3. Architecture

**100% client-side static SPA.** Files are read with the browser `FileReader`, parsed and analyzed on-device; **nothing is ever uploaded**. Deploys free to GitHub Pages when flipped public.

**Stack:** Vite + React + TypeScript + Tailwind. Vitest for unit tests. ESLint + Prettier. No router (single page, tabbed). Minimal dependencies.

**Privacy enforcement:**
- CSP `<meta>` blocking all external `connect-src` / `img-src` (no exfiltration possible even if a bug tried).
- No fetch/XHR/WebSocket anywhere; `traits.json` is bundled same-origin.
- Permanent UI banner: *"Your DNA files never leave this device."*
- No real DNA in the repo — only synthetic fixtures + demo files.

### Module boundaries (each independently testable)

```
src/
  parsers/
    detect.ts          # sniff vendor from header signature
    ancestry.ts        # AncestryDNA raw → RawCall[]
    twentythree.ts     # 23andMe raw → RawCall[]
    myheritage.ts      # MyHeritage CSV → RawCall[]
    ftdna.ts           # FamilyTreeDNA CSV → RawCall[]
```

## 4. Data formats & parsing

| Vendor | Delimiter | Genotype columns | Comment lines |
|---|---|---|---|
| 23andMe | TAB | single `genotype` (e.g. `AA`) | `#` |
| AncestryDNA | TAB | `allele1` + `allele2` (combine) | `#` |
| MyHeritage | CSV (quoted) | single `RESULT` | `#` |
| FamilyTreeDNA | CSV | single `RESULT` | header row only |

- `detect.ts` sniffs the header (e.g. `# This data file generated by 23andMe`, `RSID,CHROMOSOME,POSITION,RESULT`, AncestryDNA's `rsid\tchromosome\tposition\tallele1\tallele2`).
- All parsers emit a common `RawCall { rsid, chrom, pos, genotype }`; `--`, `00`, `II/DD/I/D` (indels) and no-calls handled.
- **Strand normalization:** each catalog SNP defines its alleles on the dbSNP `+` strand. When a genome's observed alleles are inconsistent with the SNP's known allele set, complement them (A↔T, C↔G). This fixes real vendor strand differences that single-vendor tools ignore.

## 5. The inheritance engine (centerpiece)

### 5.1 Single-locus autosomal
Each parent passes one allele at 50/50. Multiply parents' allele distributions → **child genotype distribution**. Map each genotype → phenotype probabilities from the catalog → weighted-sum → **child phenotype distribution**.

> Example (eye color, HERC2 primary): you `AG`, partner `GG` → child `{AG:50%, GG:50%}`. With penetrance `AG→{brown 70,green 23,blue 7}`, `GG→{blue 72,green 27,brown 1}` → child ≈ **blue 39% / brown 36% / green 25%** (final numbers from the multi-SNP model, see 5.3).

### 5.2 Codominant / blood type
- **ABO**: genotype from rs8176719 (O deletion) + rs8176746/rs8176747 (A/B) → allele ∈ {A,B,O}. Cross parents → child ABO distribution.
- **Rh**: RHD presence (best-effort from chip SNPs; flagged limited). Emit child Rh +/- odds and an **Rh-incompatibility note** if mother Rh− / father Rh+.

### 5.3 Multi-locus appearance (polygenic-lite)
Eye/hair color: enumerate the **joint** genotype distribution across the trait's 2–3 SNPs (each parent passes one allele per SNP; loci treated independent, with a linkage caveat noted) → feed the small joint space into an **IrisPlex-lite** style phenotype model → child phenotype distribution. Tagged `medium`.

### 5.4 X-linked
For traits like male-pattern-baldness (AR `rs6152`) and red-green color blindness: child sex 50/50; daughters get an X from each parent, sons get mother's X + father's Y. Results shown split **"if son" / "if daughter."** Tagged per evidence.

### 5.5 Missing data
If either parent lacks a required SNP → result = *"Unable to determine — needs both parents typed at rsXXXX (not on this chip)."* Never guess.

## 6. Trait catalog (v1 target — "everything sourceable")

Full machine-readable list lives in `data/traits.json`; each entry: `{ id, name, category, snps:[{rsid, plusAlleles}], inheritance, model, phenotypes, confidence, sourceUrl, pmid?, notes }`. Target set:

**Appearance** — eye color (HERC2 rs12913832 + OCA2 rs1800407 + SLC45A2 rs16891982 + TYR rs1393350), red-hair odds (MC1R rs1805007/rs1805008/rs1805009), blond-vs-brown (rs1667394, KITLG rs12821256), hair curl (TCHH rs17646946), hair thickness (EDAR rs3827760), skin pigmentation (SLC24A5 rs1426654, SLC45A2 rs16891982), freckling (IRF4 rs12203592 + MC1R), unibrow (PAX3 rs2218065). *(eye/hair `medium`; freckles/unibrow `fun`)*

**Taste & smell** — bitter taste / PTC (TAS2R38 haplotype rs713598+rs1726866+rs10246939, `high`), cilantro=soap (OR6A2 rs72921001, `medium`), asparagus-pee smell (rs4481887, `medium`), sweet preference (SLC2A2 rs5400, `fun`), alcohol flush (ALDH2 rs671, `high`).

**Metabolism & body** — lactose tolerance (MCM6 rs4988235, `high`), caffeine metabolism (CYP1A2 rs762551, `high`), caffeine-anxiety (ADORA2A rs5751876, `fun`), muscle/sprint type (ACTN3 rs1815739, `high`), earwax type (ABCC11 rs17822931, `high`), body odor (same rs17822931, `high`), pain sensitivity (COMT rs4680/rs6269, `medium`), chronotype/morning-person (CLOCK rs1801260, `fun`).

**Sensory & misc** — photic-sneeze/ACHOO (rs10427255, `fun`), misophonia (rs2937573, `fun`), motion sickness (rs66800491, `fun`), fear of heights (`fun`).

**Resistances (non-disease, inheritance-interesting)** — norovirus / FUT2 secretor (rs601338, `high`), malaria / Duffy (rs2814778, `high`).

**Blood** — ABO type + Rh factor (with incompatibility flag, `high`).

**X-linked demo** — male-pattern-baldness (AR rs6152 + 20p11 rs1160312/rs2180439, `medium`), red-green color blindness (`fun`, coverage-limited note).

> ~38–42 entries. Any SNP absent on a given chip degrades gracefully (Section 5.5). Catalog is append-only JSON — growing it post-v1 needs no code change.

## 7. Carrier / health (secondary)

`conditions.json` — recessive conditions whose variants appear on consumer chips: cystic fibrosis (CFTR ΔF508 etc.), sickle cell (HBB rs334), Tay-Sachs, hereditary hemochromatosis (HFE rs1800562/rs1799945), G6PD, alpha-1 antitrypsin (SERPINA1 rs28929474/rs17580). For each: each parent's carrier status → **offspring affected probability** (25% when both carry the same AR variant). Always tagged *educational; confirm clinically*. Catalog honestly labeled **partial coverage**.

## 8. UI / UX

- Two drop zones: **You** / **Partner**. Auto-detect vendor, show parse summary (`723,412 SNPs loaded · AncestryDNA`).
- Tabs: **Traits · Health/Carrier · Blood type · For-fun looks**.
- `TraitCard`: trait name, your genotype, partner's genotype, a horizontal **child-outcome % bar**, confidence badge, source link, "if son/if daughter" split where X-linked.
- `ChildProfile`: a "most likely child" summary card (modal phenotype per trait).
- Permanent privacy banner + a one-screen "How this works / what's real vs fun" explainer.
- Ships with **demo files** so anyone can try without their own DNA.

## 9. Testing

Vitest, synthetic fixtures only:
- **Parsers**: one fixture per vendor → expected `RawCall[]`; no-call & indel handling; strand-flip case.
- **Punnett**: `Aa×Aa → 25/50/25`; `AA×aa → 100% Aa`; allele-distribution multiply.
- **Phenotype**: eye-color model sanity; weighted-sum correctness.
- **Blood type**: `A×B → A/B/AB/O` table; Rh incompatibility flag.
- **X-linked**: carrier-mother × affected-father color-blindness; baldness son/daughter split.
- **Missing SNP**: returns "unable to determine," never throws.

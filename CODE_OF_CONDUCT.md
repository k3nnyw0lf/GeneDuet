# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).

Be respectful, welcoming, and constructive. Harassment, discrimination, or demeaning
behavior are not tolerated. Given the subject matter, also: **never share another person's
genetic data**, and don't use the project to make claims it explicitly disclaims (medical
diagnosis, legal paternity, predicting appearance/IQ).

Report unacceptable behavior by opening an issue or contacting the repository owner.
Maintainers may remove comments, commits, or contributors that violate these norms.
